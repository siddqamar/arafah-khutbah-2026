# Contributing

Corrections and improvements are welcome.

## Important note about accuracy

This transcript was produced using **OpenAI Whisper (medium)** and may contain:

- spelling/diacritics errors
- misheard words (especially names/places)
- segmentation/timestamp drift
- occasional hallucinations or missing phrases

If you spot an issue, please open an issue or submit a pull request with the fix.

## What helps most

- Fixing transcription errors in `data/2026/ar/raw.txt`
- Fixing alignment in `data/2026/ar/timestamps.txt`
- Improving segmentation (one idea per line)
- Adding missing source details to `SOURCES.md`

## Suggested workflow

1. Create a branch
2. Make small, focused edits
3. In your PR, describe what you changed and (if relevant) the timestamp(s) you verified against the source
